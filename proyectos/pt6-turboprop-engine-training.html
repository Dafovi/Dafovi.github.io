PT6 Simulator

Simulador técnico/aeronáutico VR para Meta Quest 3 y Pico, agrupado dentro de Aviation Training Suite. Cliente confidencial, con simulación en tiempo real de sistemas internos relacionados con combustible, aire y aceleración.

Stack
Unity / C# / OpenXR / Meta XR SDK / Pico SDK / REST APIs / JSON

Contexto

Proyecto desarrollado en Xennial Digital como parte de la línea de simulación aeronáutica VR. Encaja mejor como subcaso de Aviation Training Suite que como pieza destacada independiente.

Aporte

Implementación de sistemas técnicos de simulación en tiempo real asociados a combustible, aire y aceleración, manteniendo compatibilidad con visores Meta Quest 3 y Pico.
